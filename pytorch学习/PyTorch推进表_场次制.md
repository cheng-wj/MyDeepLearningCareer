## 节奏（每周 2 场）

**周中一个晚上 3h（晚场）+ 周末一个下午（周末场）。** 下午按有效 3.5h 计（挂钟 4–5h 扣除休息与切换）。

1. **3h / 3.5h 是上限不是配额。** 状态好就做满，状态差提前收工也算当天达标。
2. **允许顺延，禁止回补。** 某场没做就顺延到下一个可用档期，不补、不合并、不硬撑。
3. **概念集快进。** P06 / P17 / P33 看视频或直接看笔记，不写代码、不算完成度。
4. **按「能跑通什么」切，不按集数切。** 每场的交付物是一个能运行的东西。
5. **连续两场没做** → 先问「这个节奏是不是排太满了」，再按下方降档规则砍。

## 场次说明

- **S1**：P06 概念集快进即可。P10–P13 不用逐个学 —— 挑 `ToTensor` / `Resize` / `RandomCrop` / `Normalize` 写进 `p10_transforms.py`，其余用到再查。
- **S2**：P17 概念集快进；`p19` / `p20` / `p21` 都很小，时间紧就合并成一个文件 `p18_p21_cnn_parts.py`。
- **S3**：P27–P29 是同一个 `p27_train_cifar.py` 的三集 —— 本场先把训练脚本骨架写出来，S4 负责跑通。
- **S4**：**唯一硬目标**。只要求跑起来 + loss 前 100 step 有下降趋势；不要求跑满 epoch、不要求准确率。
- **S5**：GPU 训练是性价比最高的一场 —— `p30` 本质是把 `p27` 复制一份加 `.to(device)` 三件套和 `argparse`，不涉及新概念。GPU 万一不可用，退回 CPU 跑 `p27` 即可，不阻塞。
- **S6**：**可永远不做**。P25（改预训练 vgg16 最后一层）对你的 Halcon/CV 路线不是必须，P33（逛 torchvision / yolov5 源码）纯属兴趣。心情好就写 10 行笔记交差。

## 里程碑与验收

| 层级 | 标准 | 什么时候算到 |
|---|---|---|
| **及格** | CIFAR10 跑完 1 epoch，loss 有下降趋势 | **S4**（10-24/25 场） |
| 及格 + | 验证脚本能加载 checkpoint 算出 accuracy | **S5**（10-28/29 场） |
| **加分** | test acc > 10% | 随缘，不追 |
| 加分 + | 迁移学习 / GPU 训练都跑过 | 随缘，不追 |
| 不追 | 29 项全勾 / 10 天 commit 齐 / 复盘报告 | **已从计划中移除** |

## 降档规则（哪场做不动时按顺序砍，砍完就收工）

1. 先砍概念集（P06 / P17 / P33）—— 本来就快进，不心疼
2. 再砍 transforms 里不常用的那几个
3. 再砍 TensorBoard（P08 / P09，纯工具，不影响后面任何一集）
4. 绝对不砍 **S4 的训练跑通** —— 那是整个计划的硬目标
5. 如果连 S4 都做不完 → S5 / S6 顺延到下一档期，优先保证「数据管线 + 模型组件 + 训练」三块自己写过一遍

**连续两场没做**，不要问「怎么补偿」，直接问「这个节奏是不是又排太满了」。
