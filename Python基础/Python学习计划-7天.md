## 七、报错自救三步（够用三个月）

1. 只看 traceback **最后一行**：`NameError` = 名字没定义/拼错；`TypeError` = 类型或参数不对；`AttributeError` = 对象没这个方法/属性；`IndexError` = 越界。
2. 出问题的行前面加 `print(变量)`，看它的**实际值和类型**（`type(x)`、`len(x)`），别猜。
3. 进 PyTorch 后：**每层后面打印 `.shape`**，九成的 bug 是形状不匹配。
